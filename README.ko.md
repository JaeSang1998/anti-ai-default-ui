# Anti-AI Default UI

[![skills.sh](https://skills.sh/b/JaeSang1998/anti-ai-default-ui)](https://skills.sh/JaeSang1998/anti-ai-default-ui)

[English](README.md) · **한국어**

웹·앱 작업을 위한 금지 목록. 에이전트가 인터페이스를 만들거나 고치기 전에 읽는다.

서로 다른 에이전트에 가격 페이지를 시켜보면 대체로 같은 페이지가 나온다. 헤더 뒤에 깔린 그라디언트, 가운데 큰 제목 위에 얹힌 알약 라벨, 회색 부연 설명, 크기가 똑같은 카드 세 장, 줄마다 붙은 색 입힌 아이콘 타일. 이건 결정이 아니라 기본값이다. 제품에 필요하든 아니든 나오고, 완성돼 보이기 때문에 리뷰를 통과한다. 이 목록은 그런 수를 선택지에서 빼서, 남는 선택이 제품에서 나오게 한다.

지시문은 `SKILL.md` 하나로 관리한다. Codex는 이 파일을 스킬로 읽고, Claude Code는 `SKILL.md`를 불러오는 `CLAUDE.md`를 통해 같은 내용을 읽는다. 에이전트마다 사본을 두지 않는다.

## 무엇을 막는가

- **시각적 기본값** — 파랑-보라·보라-분홍 그라디언트, 방사형 글로우, 떠다니는 블러 덩어리, 글래스모피즘, 흰색 반투명 테두리를 두른 검정에 가까운 다크 테마.
- **히어로·마케팅 템플릿** — 알약 라벨에서 큰 제목, 회색 부연, CTA로 이어지는 구성. 비중이 비슷한 주요 버튼 두 개. 어느 제품에 붙여도 말이 되는 SaaS 문구. 지어낸 수치와 후기.
- **카드와 테두리** — 세 장짜리 기능 카드, 통계와 FAQ까지 전부 감싸는 둥근 카드, 한쪽 변에만 넣은 강조선, 같은 영역을 겹겹이 두른 테두리.
- **형태와 레이아웃** — 버튼·아바타·모달·패널에 똑같이 먹인 모서리 반경, 내용과 무관하게 적용한 8pt 간격, 떠 있는 사각형을 쌓아 만든 페이지.
- **아이콘과 컴포넌트** — 얇은 선 아이콘 세트를 제품 정체성 대신 쓰는 것, 색 입힌 둥근 사각형 안에 넣은 아이콘, 기능마다 색을 달리한 타일.
- **게임·HUD화** — 평범한 소프트웨어를 관제실처럼 꾸미는 것. 빛나는 상태 램프, 경험치 같은 게이지, 조준선, 전부 대문자인 작은 제목, 군사 용어 흉내.
- **위계와 내용** — 주목 순서 없는 크기 차이, 가독성을 깎는 흐린 글씨, 상태와 검증을 색으로만 알리는 것, 실제 문구·데이터와 빈 화면·로딩·오류 상태보다 먼저 손대는 스타일링.
- **작업 방식** — 처음 나온 레이아웃에서 색만 바꾸고 넘어가기, 컴포넌트 라이브러리를 제품 정체성으로 삼기, AI 티를 지우려고 없던 장식 넣기.

전체 목록은 `SKILL.md`에 있고, 위는 그 분류다.

## 무엇을 하지 않는가

금지 목록이지 스타일 처방이 아니다. 대신 쓸 색이나 타이포 스케일, 컴포넌트 라이브러리를 정해주지 않는다. 패턴을 걷어낸 자리에 제품 판단이 필요하면 — 이 화면에서 가장 중요한 동작이 무엇인지, 데이터가 어떻게 생겼는지 — 스킬은 새 처방을 지어내지 않고 사용자에게 묻는다.

개별 금지는 명시적으로 요청하면 풀린다. 이 목록이 막는 건 기본값이지 결정이 아니다.

## 설치

[`skills` CLI](https://github.com/vercel-labs/skills)로 이 저장소를 Claude Code, Codex, Cursor 등 지원 에이전트의 스킬 디렉터리에 설치한다. `SKILL.md`가 저장소 루트에 있고 CLI가 요구하는 `name`, `description` frontmatter를 이미 갖고 있어서 따로 설정할 것이 없다.

```sh
npx skills add JaeSang1998/anti-ai-default-ui
```

이 명령은 현재 프로젝트에 설치한다. Claude Code라면 `./.claude/skills/anti-ai-default-ui/`에 들어가고, 설치된 버전은 `skills-lock.json`에 기록된다. 사용자 전역으로 설치하려면 `-g`를, 에이전트를 직접 고르는 대신 지정하려면 `-a`를 붙인다.

```sh
npx skills add JaeSang1998/anti-ai-default-ui -g -a claude-code -a codex
```

전역 설치는 `~/.claude/skills/anti-ai-default-ui/`와 `~/.codex/skills/anti-ai-default-ui/`에 쓴다. 이후 변경사항은 `npx skills update anti-ai-default-ui`로 받고, 제거는 `npx skills remove anti-ai-default-ui`로 한다.

### Codex에 직접 설치

이 저장소 디렉터리를 Codex 스킬 디렉터리에 `anti-ai-default-ui`라는 이름으로 복사하거나 심볼릭 링크를 건 뒤 `$anti-ai-default-ui`로 부른다.

```sh
git clone https://github.com/JaeSang1998/anti-ai-default-ui.git
cp -R anti-ai-default-ui ~/.codex/skills/anti-ai-default-ui
```

### Claude Code에 직접 설치

Claude Code는 프로젝트 디렉터리의 `CLAUDE.md`를 자동으로 읽는다. 이 저장소를 프로젝트 안에 클론하거나, 프로젝트나 사용자 수준 `CLAUDE.md`에서 `SKILL.md`를 불러온다.

```md
@/absolute/path/to/anti-ai-default-ui/SKILL.md
```

저장소에 포함된 `CLAUDE.md`에 이 구문이 이미 들어 있어서 같은 지시문을 두 벌 관리할 일은 없다.

## 동작 방식

**Codex.** `$anti-ai-default-ui`로 스킬을 부른다. 표시 이름과 Codex가 제안하는 기본 프롬프트는 `agents/openai.yaml`에 있다. 기본 프롬프트는 *Use $anti-ai-default-ui to create or review this interface.* 다.

**Claude Code.** 스킬 디렉터리에 설치하면 작업이 스킬 설명과 맞을 때, 그러니까 인터페이스를 만들거나 고칠 때 불러온다. `CLAUDE.md`로 불러오는 방식은 성격이 다르다. 해당 프로젝트의 모든 턴에서 규칙을 컨텍스트에 유지한다. 항상 켜두고 싶으면 이쪽을 쓴다.

## 예시

같은 에이전트에 같은 요청을 한다. *가격 페이지 만들어줘.*

**스킬 없이.** 헤더 뒤에 그라디언트가 깔린다. "Pricing"이라고 적힌 알약이 커다란 가운데 제목 위에 뜨고 그 아래 회색 부연이 붙는다. 같은 크기 카드 세 장이 이어지는데 가운데 것만 커져 있고, 기능 줄마다 색 입힌 아이콘 타일이 앞에 선다. 페이지의 모든 모서리가 같은 반경을 쓴다. 어느 것도 요금제에서 나오지 않았다. 요청의 생김새에서 나왔다.

**스킬을 켜면.** 그 수들이 막히면서, 그것들이 덮고 있던 질문이 드러난다. 어떤 요금제를 대부분의 사람이 골라야 하고, "Most popular" 알약 없이 그걸 어떻게 보여줄 것인가. 번역하면 가장 긴 요금제 이름은 얼마나 길어지는가. 가격을 불러오는 동안, 그리고 결제 API가 실패했을 때 페이지는 무엇을 보여주는가. 에이전트는 제품에서 답을 찾거나 사용자에게 되묻는다.

스킬은 그 페이지의 대체 디자인을 내놓지 않는다. 기본값을 걷어내고 결정을 남긴다.
